# Capiluxe · démo boutique en ligne

Maquette de site e-commerce pour **Capiluxe**, soins capillaires naturels à Saint-Louis ([@capiluxe221](https://www.tiktok.com/@capiluxe221)).

- Catalogue, filtre par besoin (pousse, crépus, locks, enfants), gammes complètes
- Commande avec paiement à la livraison, Wave ou Orange Money
- Commande envoyée sur WhatsApp, déjà rédigée
- Espace commandes avec statuts (démo locale au navigateur)

Démo réalisée par Babacar Sy. Prix et visuels indicatifs.
